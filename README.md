# Project Cocos

A Cocos Creator **2.4.13** game. English/Chinese localization and layout work is in progress; the initial Git checkpoint is a recovery snapshot, not a release certification.

Open this folder in Cocos Creator 2.4.13. Allow Creator to regenerate its imported assets and caches. The startup scene is configured in `settings/builder.json`.

- [Version history, GitKraken, and working on another computer](docs/VERSION_CONTROL.md)
- [Translation tables and localization workflow](docs/LOCALIZATION.md)

The repository includes game assets, scripts, scenes, prefabs, `.meta` files, project settings, editor packages, localization tools, and the original source archive. Generated Cocos caches, local recovery files, installed dependencies, and credentials are excluded.
