# English UI visual QA checklist

This inventory covers all 41 UI/controller prefabs currently present. A static localization pass is not visual sign-off. Rows remain unchecked unless a current screenshot has been reviewed; the status column distinguishes the limited live evidence already reported.

Use the isolated QA preview at 375 px wide first, then the intended desktop/mobile viewport. For each screen, inspect both fresh opening and English→Chinese→English while it remains open. Check actual dynamic text, centered bounds, complete lines, outlines, wrapping, neighboring controls, touch targets and any baked/Spine lettering. Record a screenshot and the exact content/state before marking a row complete. Do not reset or advance the user's save to manufacture test states.

## Highest-priority gaps

Gear and weapon offers, Settings, Achievements, long Talent descriptions, the battle perk chooser, building upgrades, pause and both result flows need the next screenshots. The home stage title has a dedicated patch ready for verification. Shop does not have a playable screen: ButtonUnlock requires stage 30 / wave 10, only 20 stages are configured, and preShop has no prefab assigned. Verify the localized Coming Soon response rather than treating a nonexistent shop as tested.
